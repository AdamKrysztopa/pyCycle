# Regression Data Management

This document describes how pyCycle regression data is stored and updated.

## Location
Regression data files live under:
- `pycycle/elements/test/reg_data/`

These CSVs are used by element tests to validate stable outputs for known inputs.

## How Data Is Generated
Regression data is generated by running the element-level tests that write reference outputs.
The canonical sources are the test modules under:
- `pycycle/elements/test/`

When physics or numerical behavior changes, re-run the relevant element tests to regenerate
reference data and confirm the new outputs are intentional.

## Update Workflow
1. Identify the element(s) affected by the change.
2. Run the associated tests to regenerate data (see `Makefile` targets).
3. Review the updated CSV files for expected changes.
4. Commit the updated regression data alongside code changes.

## Precision Expectations
- Data is stored at full CSV precision produced by the tests.
- If tolerances need adjustment, update the test assertions rather than truncating data.

## Notes
- Keep regression updates tightly scoped to the elements you changed.
- If a broad physics change impacts many elements, document the rationale in the PR.
